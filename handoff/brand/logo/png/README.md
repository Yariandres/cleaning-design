# Favicon and app-icon bitmaps

> **DRAFT — awaiting the owner's approval (2026-11-16).** Part of the draft `stroller-v1.2`.

Rendered from the approved SVGs one folder up (logo direction B, approved 2026-11-13). Nothing was redrawn. Generated by us; no third-party artwork. Regenerate with `node prototypes/stroller/tools/render.mjs <svg> <w> <h> <out.png> t` (the last argument keeps the corners transparent).

| File | From | Use |
|---|---|---|
| `favicon.ico` (16, 32, 48) | `mark-small.svg` (8 petals) | `/favicon.ico`: the fallback for browsers and crawlers that do not take the SVG favicon |
| `favicon-32.png` | `mark-small.svg` | optional `<link rel="icon" type="image/png" sizes="32x32">` |
| `apple-touch-icon.png` (180, square, opaque) | `app-icon.svg` with square corners | `<link rel="apple-touch-icon">` for the **public site** (iOS rounds the corners itself; a transparent or pre-rounded icon gets a black edge) |
| `icon-192.png`, `icon-512.png` | `app-icon.svg` | web manifest, purpose `any` |
| `icon-maskable-512.png` | `app-icon-maskable.svg` | web manifest, purpose `maskable` |

The SVG favicon stays the primary (`mark-small.svg`, already at `/favicon.svg` in the app). Checked at 16, 32, 48 and 180px on light and dark: `handoff/pages/stroller-counter/screens/30-favicon-app-icon-sizes.png`. Theme colour: `neutral-50` `#F5FAF8`.
